<h1>🏥 Healthcare Data Visualization</h1>
<p>This project focuses on exploring and understanding key trends in healthcare data using Python. By leveraging powerful libraries such as <code>pandas</code>, <code>matplotlib</code>, and <code>seaborn</code>, it extracts and visualizes insights from patient-level data across multiple dimensions.</p>

<h2>📊 Project Objective</h2>
<p>The goal is to perform exploratory data analysis (EDA) and visualize healthcare-related metrics, including:</p>
<ul>
  <li>Patient age distribution</li>
  <li>Gender-based analysis</li>
  <li>Disease frequency</li>
  <li>Relationship between age and diagnosis</li>
  <li>Hospital visit analysis</li>
</ul>
<p>These insights help identify patterns, anomalies, and opportunities in healthcare data, supporting informed decision-making and enhancing patient outcomes.</p>

<h2>🛠 Tools & Technologies</h2>
<ul>
  <li>Python (Jupyter Notebook)</li>
  <li>Pandas</li>
  <li>Matplotlib</li>
  <li>Seaborn</li>
</ul>

<h2>📁 Dataset Overview</h2>
<p>The project uses a synthetic healthcare dataset (in CSV format) containing the following features:</p>
<ul>
  <li><code>Patient_ID</code></li>
  <li><code>Age</code></li>
  <li><code>Gender</code></li>
  <li><code>Diagnosis</code></li>
  <li><code>Hospital</code></li>
  <li><code>Visit_Date</code></li>
  <li><code>Treatment_Cost</code></li>
</ul>
<p><strong>Note:</strong> The dataset is anonymized and does not contain any personally identifiable information (PII).</p>

<h2>📈 Visualizations Included</h2>
<ul>
  <li>Patient distribution analysis based on age and billing amount</li>
  <li>Distribution of patient counts across categorical features (bar and pie charts)</li>
  <li>Revenue and billing amount distribution by medical condition and prescribed medication</li>
  <li>Billing amount analysis based on medical condition and test results</li>
  <li>Top features by average number of days hospitalized</li>
</ul>

<h2>🧠 Skills Demonstrated</h2>
<ul>
  <li>Data cleaning, preprocessing, and transformation using <code>pandas</code></li>
  <li>Exploratory Data Analysis (EDA) with descriptive statistics</li>
  <li>Visualization of healthcare trends using <code>matplotlib</code> and <code>seaborn</code></li>
  <li>Deriving insights from patient demographics and hospital metrics</li>
  <li>Presenting findings effectively in a well-structured Jupyter Notebook</li>
</ul>
